    我的腾讯会议（方案① · 固定个人会议号）

    填一次你的固定会议号与入会链接，新建/编辑会议日程会自动带入。所有人共用同一会议室，可能撞会。

    修改我的口令

    自助修改的口令仅本人知晓（管理员也不可查看）。新口令至少 6 位；修改后旧令牌 7 天内仍有效，建议重新登录。

    成员管理（管理员）

    修改成员角色后，该成员需重新登录方可生效（令牌 7 天有效，期内仍持原角色）。不能修改自己的角色。

    3 · 通用

    日程数据（JSON 导入/导出）

    导入需要先登录（导入会写入当前团队的日程表）。
    文件格式：{ "items": [ { "title": "部门周例会", "table": "work", "type": "meeting", "startTime": "2026-10-28 10:00", "endTime": "2026-10-28 11:00", "ownerKey": "self" } ] }
    必填 title 与时间；table 取 work/daily； 缺 endTime 自动按开始时间 +30 分钟。
    导入是「合并」不是覆盖：只新增，不清空已有日程；已存在的（同标题同时段同归属）自动跳过。
    导出的 JSON 可直接再导入（同一团队内不会重复堆积）。图片 / Excel 识别尚未开通。
